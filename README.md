# Power BI Sales & Revenue Analysis Dashboard 

## Project Overview

This project is an interactive Sales and Revenue Analysis Dashboard created using Microsoft Power BI.
The dashboard helps analyze sales performance, revenue trends, product performance, and other important business insights through interactive visualizations and filters.

##  Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Features

- Total Sales analysis
- Revenue analysis
- Sales trend analysis
- Top-performing products
- Category-wise analysis
- Interactive filters and slicers
- KPI cards
- Data visualizations
